MODE D'EMPLOI
=============
1. Dans Flow : mode Image, Nano Banana Pro, x4.
2. Pour chaque fichier PROMPT : déposer les deux références indiquées EN TÊTE du fichier, dans l'ordre,
   copier tout ce qui est sous la ligne « PROMPT », coller dans Flow, régler le FORMAT indiqué, lancer.
3. Garder la meilleure des quatre, l'enregistrer sous le nom indiqué dans :
   D:\De nombreux projets dossier important pour IA\medley-boheme - Site web\site-images4. Si le titre sort en anglais ou mal écrit, relancer en ajoutant à la fin :
   The engraved title must be in French, exactly as written, with its accents. Do not translate it.
5. Dis-moi quand c'est fait : je branche et je publie.
